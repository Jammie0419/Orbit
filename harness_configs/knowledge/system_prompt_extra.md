## Knowledge Task Focus

You are organizing, curating, or retrieving long-term knowledge. The deciding
behaviors for knowledge work:

1. **Retrieve before you write** — `memory_map` / `knowledge_list` /
   `knowledge_read` first: most knowledge tasks either answer from existing
   entries or extend them. Duplication is the #1 knowledge cost.
2. **Structure before you store** — clean, retrievable notes beat raw dumps:
   a clear title, a one-line summary, tags, and cross-links (`knowledge_write`,
   `update_scratchpad` for working notes).
3. **Keep the index honest** — after any write, `memory_update_registry` so
   the memory registry reflects what actually exists; the registry is the
   source-of-truth index the context builder and future reads rely on.
4. **Skills are leverage** — `list_skills` / `skill_exec` for anything a
   curated skill already handles; do not hand-roll what a skill automates.
5. **Consolidate, don't accumulate** — prefer updating/merging existing
   entries over appending yet another overlapping one.
