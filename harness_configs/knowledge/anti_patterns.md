- **Write without retrieving** — creating a new entry when a similar one
  already exists; always `knowledge_read` / `knowledge_list` first.
- **Storing raw dumps** — unedited file contents or chat logs; knowledge is
  the distilled version with structure and tags.
- **Writing without indexing** — entries that never reach the memory registry
  become unreachable knowledge.
- **Orphan notes** — notes with no title, no tags, and no cross-link; they
  will never be found again.
- **Re-reading what is already loaded** — memory sections are injected into
  context; do not `read_file` them from disk.
