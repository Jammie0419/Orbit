## Simple Task Focus

Keep it brief and direct. This is a lightweight turn:

1. **Answer with the minimum needed** — no ceremony, no sprawling tool chains.
2. **Use chat/recent context** — `chat_history` / `recent_tasks` for continuity.
3. **Only escalate when needed** — if the turn turns out non-trivial, say so and
   take the heavier path rather than half-answering.
